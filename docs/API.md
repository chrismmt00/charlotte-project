# Klyvora API

Routes use the services in `src/lib/server/`. Existing route files are thin exports; the catch-all serves additional endpoints. JSON errors have `{ error: { code, message, fields? } }`. API responses use dollars for frontend display; database/provider amounts use integer cents. Authenticated responses are private/no-store.

| Signed provider     | `POST /api/stripe/webhook`                                                                          | Verified billing/Connect signatures; durable event deduplication, invoice/subscription reconciliation                                                                                        |
| Cron bearer         | `GET/POST /api/jobs`                                                                                | Durable background worker; retries provider failures with backoff                                                                                                                            |

Notifications and billing jobs are durable PostgreSQL rows. A small batch runs after successful mutations; daily Vercel Cron retries pending work. An email waiting in the queue is not evidence of delivery. Failed jobs can be inspected/retried by an operator.

Private R2 storage, client handover repositories, an external prospecting agent, and a separate preview Neon branch require their own configuration. Unsupported automatic installment charges fail explicitly; partial Stripe payments should be recorded in Stripe and reconciled by webhook. Client product checkout engines remain separate from the company operations app, as specified in the site plan.
